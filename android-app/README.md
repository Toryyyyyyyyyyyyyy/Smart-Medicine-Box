# 智能药箱 App（使用说明）

面向使用者的安装与使用指南。你不需要下载源码——请直接下载 [Releases](https://github.com/Toryyyyyyyyyyyyyy/Smart-Medicine-Box/releases) 中打包好的 APK 与后端压缩包。

## 一、安装 App

1. 在 Releases 页面下载最新的 `app-*.apk`；
2. 传到手机并点击安装（首次安装需在系统提示中允许「安装未知来源应用」）；
3. 支持 Android 8.0（API 26）及以上。

## 二、准备后端（想要同步/家属功能时才需要）

纯本地提醒无需后端，跳过本节即可。

1. 从 Releases 下载 `backend.zip`，在电脑上解压；
2. 按压缩包内 `DEPLOY.md` 的步骤启动后端（局域网直连或公网域名两种模式）；
3. 记下后端的 https 地址。

## 三、配置服务器地址（仅 https）

App 内：**我的 → 服务器**，填写后端地址：

| 场景 | 地址 |
|---|---|
| 安卓模拟器 | `https://10.0.2.2:8000` |
| 手机与电脑同一局域网 | `https://<电脑局域网IP>:8000` |
| 公网部署 | `https://<你的域名>` |

App 只接受 https 地址，明文 http 会被拒绝。

**局域网服务器需配对一次**：在电脑后端目录执行 `python cli.py pair` 得到 8 位配对码，在 App 弹出的配对窗口输入即可。配对后 App 永久信任该服务器；若提示「服务器身份已改变」，请重新配对（说明后端证书已更换）。

## 四、注册 / 登录

- 可注册账号登录（数据端到端加密同步到服务器），也可**跳过登录纯离线使用**；
- 一个账号同一时刻只能在一台设备登录（新登录会使旧设备下线）；
- 退出登录不删除本地数据。

## 五、需要授权的权限（按系统提示逐项开启）

| 权限 | 用途 |
|---|---|
| 通知 / 精确闹钟 / 全屏通知（Android 14+） | 到点提醒 |
| 悬浮窗 + 后台弹窗（华为/鸿蒙必开） | 锁屏全屏弹窗 |
| 忽略电池优化 | 防后台被杀 |
| 自启动（华为/鸿蒙：手机管家 → 启动管理） | 开机自动运行 |
| 相机 / 相册 | 选择自定义提醒视频 |

权限状态可在 **我的 → 权限管理** 中逐项查看和跳转开启。

## 六、主要功能速览

- **药品页**：添加药品（名称/剂量/重复方式/时间点/库存/备注/铃声震动视频），主按钮「服用」对应今天最早未处理剂量；到点全屏弹窗，可「已服用 / 5分钟后提醒 / 暂不服用」；
- **记录页**：查看、删除、撤销（仅当天）服药记录；
- **家属控制**：控制对象在账号页开启并设置家人控制密码；家属输入其 8 位用户id + 家人控制密码远程查看/记录（45 分钟内控制设备需连接过服务器）；
- **管理网站**：浏览器打开后端地址的 `/admin`，管理员账号登录（初始 `Admin/123456`，请立即修改）。
